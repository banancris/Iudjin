index.html conține interfața completă, stilurile și logica JavaScript.
Este un site static: îl poți deschide direct în browser sau îl poți servi de pe un hosting static.
Lista de active este păstrată local în browser (localStorage). Nu există autentificare, backend sau cotații live.
dist/index.html este copia pregătită pentru publicare, iar .openai/hosting.json este manifestul proiectului.
